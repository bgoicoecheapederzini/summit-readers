# Summit Readers

A free-time reading challenge for third graders. Students sign in with a class code and PIN, read for 15 minutes, show what they read, and move their team up a level map after the teacher approves their work.

- `index.html` and `student.js`: the student site
- `teacher.html` and `teacher.js`: the teacher panel
- `shared.js` and `style.css`: shared code and styles
- `supabase/migrations`: the database

The site is static and only calls database functions. Student data stays in the database, not in this repository.
